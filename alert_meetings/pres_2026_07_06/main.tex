    \begin{center}
        {\color{blue}(vz shift)} $=$ {\color{red} (CLAS Upstream VZ peak)} $+$ {\color{RoyalBlue}(ALERT Survey location)}

    \begin{itemize}
        \item {\color{RoyalBlue}(ALERT Survey location)} is 39.94 mm from the CLAS Upstream VZ peak location

            \begin{itemize}
                \item up to 3 cm shift between the inbending and outbending values
            \end{itemize}
        \item The true {\color{blue}(vz shift)} value is obtained by alignment for each configuration
    \end{itemize}
